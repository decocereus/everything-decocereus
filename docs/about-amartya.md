### Nexus

#### Product problem

User funds are fragmented across chains and tokens. Nexus brings those balances together so applications can source, bridge, swap, and execute without forcing users through separate manual flows.

Nexus is a broader product, not merely a “developer product.” The SDK and installable UI are the parts Amartya built for integration teams.

#### Ownership and decisions

- Built the initial Nexus SDK integration surface for frontend developers.
- Built UI components on top of the headless SDK.
- Drove the decision to separate UI from the SDK when the combined package limited customization and imposed unnecessary package weight.
- Rebuilt the UI as source-owned shadcn components installed through a registry command, allowing integrators to own and edit the source.
- Built and maintained the Nexus Elements distribution site and shadcn registry integration.
- Added and iterated on bridge, swap, and swap-and-execute flows.
- Influenced UI design and UX architecture and drove the release strategy during the relevant period.
- Helped build a Hyperliquid extension for deposits that received strong attention on X.

#### Evidence and scale

- The early combined package was roughly 8 MB unpacked when source maps and dependencies were bundled, later falling to roughly 1 MB after dependencies were externalized and source maps removed. These are self-reported rounded figures.
- A verified public package comparison found a reduction from **14.9 MB to 1.6 MB npm unpacked size**, approximately **89%**. Name the package versions when finalizing any public claim.
- “25+ Nexus integrations” can describe the broader ecosystem only. Do not imply that every integration was directly attributable to Amartya.
- Public artifacts can include the SDK repository, Elements repository and site, npm package history, and relevant commits or pull requests.

The best case-study angle is the product and architecture decision to separate a headless SDK from source-owned, shadcn-distributed UI, rather than generic cross-chain terminology or package-size trivia.
